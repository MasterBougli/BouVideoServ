# Utilisation

## Avant de commencer

- Verifie que le moteur RTMP est actif
- Verifie que la machine est accessible sur le reseau local
- Verifie qu'OBS ou la camera publie vers la bonne URL
- Verifie que le serveur Rust est lance correctement

## Exemple d'envoi

```text
rtmp://127.0.0.1:1935/camera1
```

## Bonnes pratiques

- nomme chaque flux clairement
- garde une convention stable pour les cameras
- utilise les cartes camera une par une pour rester lisible
- surveille l'espace disque des enregistrements
- commence par peu de flux puis ajoute progressivement
