# Installation

1. Recuperer le projet.
2. Placer `bouvideoserv` et `mediamtx` dans `bin/`.
3. Lancer `scripts/start-linux.sh` ou `scripts/start-windows.ps1`.
4. Ouvrir l'adresse affichee dans la console.

## Fichiers importants

- `data/config.json`
- `mediamtx/mediamtx.yml`
- `data/recordings/`
- `data/cache/`
