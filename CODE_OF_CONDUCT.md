# Code of Conduct

BouVideoServ veut rester un projet simple, utile et accueillant.

## Attentes

- Sois respectueux
- Reste factuel et constructif
- Critique le code, pas les personnes
- Accepte les retours avec ouverture

## Comportements a eviter

- Insultes ou harcelement
- Comportement agressif
- Pression ou intimidation
- Spam ou sabotage des issues et pull requests

## Signalement

Si un probleme de comportement apparait, ouvre une issue privee ou contacte
l'auteur du projet par le canal habituel du depot.
