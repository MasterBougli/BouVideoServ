# Contributing

Merci de contribuer a BouVideoServ.

## Base de contribution

- Ouvre une issue avant une grosse modification
- Une pull request doit rester petite et lisible
- Le code doit rester simple et portable sur Windows et Linux
- Les messages de commit doivent etre clairs

## DCO

Ce projet utilise un Developer Certificate of Origin leger.

Chaque commit ou pull request doit contenir le sign-off suivant:

```text
Signed-off-by: Prenom Nom <email@example.com>
```
