# Developer Certificate of Origin

BouVideoServ attend des contributions avec sign-off.

En envoyant un commit ou une pull request, tu confirmes que:

- tu as le droit de soumettre ce code
- tu acceptes que ta contribution soit utilisee dans BouVideoServ
- tu signes chaque contribution avec:

```text
Signed-off-by: Prenom Nom <email@example.com>
```
